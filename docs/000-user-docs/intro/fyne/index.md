# The Fyne UI Library

[Fyne](https://docs.fyne.io) is a Go-based cross-platform Graphical User Interface framework. Final uses this framework for the final-gui interface, and for all of its GUI components.

This section introduces you to the Fyne Library, and how Final presents it to you. The next chapter covers the basic concepts of the library, the following chapter briefly covers the Fyne widgets, layouts, and helper objects available in Final.

The [SimGame Framework](../sims-and-games.md) also uses the Fyne library, as well as Final's [Raster Drawing](../blit-draw/index.md) framework.

Future releases of Final are likely to expand Fyne support.
