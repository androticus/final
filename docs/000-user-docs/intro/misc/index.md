# Misc

Small utilities and development aids that do not belong in a larger topic family.

They include:
* the useful `forget:` word for resetting the dictionary to before the word
* `Counter`, `Average`, and `MovingAverage` types for running totals/averages
* `Rand` and `Noise` for creating random numbers and Perlin noise (useful for things like terrain maps, where near neighbors want to be random but related.)
* `Stopwatch` for measuring elapsed time from a starting point
